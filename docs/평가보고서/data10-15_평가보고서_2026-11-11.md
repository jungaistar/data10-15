## 3. 기능과 시험

기획서의 기능 7가지와 계산 규칙 시험 32개입니다.

| 기능 | 내용 |
|---|---|
| 합의 결과 가져오기 | 엑셀 여러 개를 읽고 열 이름이 달라도 찾아 연결합니다. 협력사별로 건수 · 합의합계 · 부가세 · 총액을 묶습니다. |

## 7. 한계와 남은 일

- 업무 자료(합의 결과 · 양식 · 발행 이력)는 아직 팀 공유 DB 가 아니라 이 브라우저에 저장됩니다(다른 PC 로는 JSON 백업).
- 회사 양식 그대로의 PDF 자동 변환은 하지 않습니다 — 인쇄용 기본 양식을 PDF 로 저장하거나 받은 엑셀에서 저장합니다.
- 결재 · 메일 발송은 하지 않습니다.
- 도형 · 글상자 안의 키, 한 시트에 반복 표 두 개, .xls · 문서보안(DRM) 양식은 다루지 않습니다.
- 실제 합의 결과 · 회사 양식은 아직 받지 않아 샘플은 가상 협력사 6곳 · 22행입니다.
- 로그인 뒤 화면(게시판 · 관리 · 첫 화면 고르기)은 가짜 Supabase 로 화면 흐름을, 로컬 PostgreSQL 과 과정용 프로젝트에서 SQL 권한을 확인했습니다. 실제 계정으로 로그인해 누르는 확인은 요청자 몫입니다.
- 독립 운영까지 남은 것: 본인 Supabase 프로젝트에 auth.sql · board.sql · site.sql 실행 → js/auth-config.js 의 url · anonKey 교체 → 다시 배포(supabase/README.md)
